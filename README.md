# Um pouco sobre cada projeto...
Esses projetos foram feitos no curso do _balta.io_ e foram a minha introdução ao C# como linguagem. 
Cada um deles explora um pouco os conceitos basilares da sintaxe e capacidade como também das limitações da linguagem, ensinando os conceitos de namespace, funções, cultura e muitos outros.\
Também é importante ressaltar que esses projetos foram alterados e melhorados em relação ao original para melhorar e aprender mais sobre o C#.\
Agora, um resumo de cada um deles.
## Calculadora
O primeiro projeto, aquele que ensina sobre somas, funções, retornos e lógica básica de cada linguagem.
Ensinou também alguns comandos importantes para criar aplicações em console.
## Cronometro
O projeto que continuou nas bases do primeiro, mas que exigiu que houvesse pesquisa na documentação e uma implementação diferente para atender à demanda.
## Editor de texto
Um editor de texto básico para escrever e sobrescrever arquivos de texto.
## Editor HTML
Projeto que melhora um pouco o editor de texto, exige uma organização maior de funções e namespaces.
